# AI Security Briefing — October 18, 2026

**Bottom line:** One notable new disclosure — OpenCode's Console breach exposing OpenAI/Anthropic/Google API keys via a "distillation attack" — but it's excluded from Section 3 for the same reason as recent similar items: a vendor-platform breach with no disclosed technical mechanism, rather than a named flaw in agent/tool architecture.

## 1. OpenCode Console breach — stolen provider API keys used for a "distillation attack" (disclosed Oct 17, 2026)

OpenCode (an AI coding-agent platform) disclosed that attackers breached a legacy backend system slated for retirement and accessed stored third-party API keys for 1.4% of Console users who had linked their own OpenAI, Anthropic, and/or Google credentials. Attackers used the stolen keys to run high-volume queries against frontier models — described by OpenCode only as "a large-scale distillation attack," with no further technical detail released — racking up unauthorized charges (some victims report hundreds of dollars) before OpenCode caught it. The company is notifying affected users and working with all three providers; no CVE or specific vulnerability mechanism has been published.

**Why no Section 3 edit:** this fails the same test recent exclusions (Tensorlake/ChainDrop, Vercel/Context.ai) failed — "attributed to a legacy system" names no specific attack vector in agent/tool architecture, just an unspecified backend compromise that happened to expose AI-provider credentials. The "distillation attack" detail describes the attacker's downstream use of the stolen keys, not the breach mechanism itself. Flagging it anyway because it's a real, named, dated incident with confirmed financial harm, and "steal API keys specifically to distill a frontier model at the victim's expense" is a genuinely novel misuse pattern worth having on record even without a Section 3 home — if OpenCode or another vendor ever discloses the actual technical mechanism behind one of these legacy-system breaches, that would be the trigger to reconsider.

Source: Notebookcheck, Cyera, CryptoBriefing, Blockonomi (OpenCode's own disclosure email is the underlying primary source; provider list and dollar amounts vary slightly by secondary outlet).
