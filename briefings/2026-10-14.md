## Noted and excluded

- **Tensorlake npm package compromise — ChainDrop/Shai-Hulud worm (published Oct 8, 2026):** version 0.5.144 of the `tensorlake` npm package (an AI document-extraction/agent SDK) was compromised via a maintainer-account/CI takeover and carried a self-propagating credential-stealing worm (preinstall-hook execution, harvesting npm/GitHub/AWS/Kubernetes tokens, SSH keys, and — notably — configuration files for AI tools including Claude). Part of the broader ChainDrop/Shai-Hulud campaign that began in August 2026 with the Keyv package and has since hit 400-1,300+ unrelated npm packages.

  **Why excluded from Section 3:** this is a generic, ecosystem-wide supply-chain worm that happened to land on an AI-adjacent package — it's not a design flaw in an agent framework, MCP server, or runtime (the way GitSpawn's git-ref-resolution bypass, already in Row 6, is). The "steals AI tool configs" detail is one line item in a much broader credential-harvesting payload that targets every developer on the machine, AI-related or not. Flagging explicitly so it isn't silently dropped; would reconsider as a Section 3 candidate only if Spencer wants AI-adjacent supply-chain compromises tracked as their own forward-looking category, rather than shoehorning this single incident into an existing row.

  Sources: [The Hacker News](https://thehackernews.com/2026/10/tensorlake-npm-package-compromised-to.html); SC World; Endor Labs; Aikido; CyberSecurityNews.
