## 1. Unit 42: indirect prompt injection is now active in the wild, not theoretical — candidate second precedent for Row 2 (Agent & State)

Palo Alto Networks' Unit 42 published "Fooling AI Agents: Web-Based Indirect Prompt Injection Observed in the Wild" (Sept 29), cataloging 22 distinct payload-delivery techniques — hidden or manipulated instructions embedded in web content that an AI agent later ingests — and documenting concrete, financially-motivated real-world cases: forced PayPal transfers of $5,000, Stripe-based subscription fraud, recursive file deletion in IDE-integrated coding agents, API key exfiltration, biased recruitment screening, and the first observed case of an injection payload built specifically to bypass an AI-based ad-review system (24 distinct injection attempts on reviewerpress.com pushing a fake military-glasses discount).

- Source: [Unit 42 (Palo Alto Networks)](https://unit42.paloaltonetworks.com/ai-agent-prompt-injection/)
- **Why this matters:** This is a volume/diversity escalation, not a single new technique — Unit 42 frames it plainly as indirect prompt injection moving from theoretical to actively exploited in production. It's a concrete new diligence question for clients: ask vendors whether their agents ever ingest untrusted third-party web content (search results, scraped pages, ad networks), and what indirect-injection filtering applies specifically to that content.

## 2. DIVD: a Dutch security nonprofit breached via an attacker's autonomous AI agent (noted, not queued as a doc edit)

The Dutch Institute for Vulnerability Disclosure (DIVD) disclosed being breached after seven years of uneventful operations. A threat actor exploited a technical vulnerability in an undisclosed system (DIVD confirmed it was not Citrix NetScaler), then used an autonomous AI agent for post-exploitation — password spraying and an adversary-in-the-middle attack — with DIVD describing the agent as choosing its next action after each step "at the speed of light and sloppy logic or pattern," rather than following a fixed script. DIVD has informed police, the Dutch data protection authority, and the national cybersecurity center.

- Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/automated-ai-agent-used-to-breach-cybersecurity-nonprofit-divd/)
- **Why this matters:** This is a real, named incident of an attacker wielding an autonomous AI agent as an offensive tool against a third party — worth tracking as an evolving threat-landscape signal — but it's a different category from your doc's existing Section 3 precedents, which track an enterprise's own deployed agent going wrong (accidentally or via injection), not an attacker's weaponized agent. No clean MAESTRO-layer mapping identified, so it's noted here rather than queued as a doc edit — consistent with how CLOSEDQUORUM (AI-as-decision-engine malware) was handled in an earlier briefing.
