## 1. Coverage-gap flag: GitLab AI Gateway prompt-template-sandbox escape to command execution (CVE-2026-90970) — Spencer's call on backdating (5th item in the backlog)

GitLab disclosed CVE-2026-90970 (CVSS 9.9, Critical) on October 2, 2026 — missed in daily coverage at the time. A flaw in the prompt template of a GitLab Duo Agent Platform "custom flow" (a user-defined, AI-powered multi-step automation) let a logged-in user with Duo Agent Platform access escape the prompt-template sandbox via a specially crafted flow configuration, leading to arbitrary command execution on the AI Gateway host. Only self-hosted AI Gateway deployments are affected — GitLab.com, GitLab Dedicated, and Self-Managed instances using a GitLab-hosted gateway are not. Reported via HackerOne by researcher invisiblemeerkat; fixed in gateway versions 19.2.4, 19.3.2, and 19.4.1. CISA assesses exploitation as "none" — no evidence of in-the-wild exploitation or public proof-of-concept.

- Source: [SC World](https://www.scworld.com/brief/gitlab-warns-of-critical-ai-gateway-vulnerability-allowing-command-execution), [Security Affairs](https://securityaffairs.com/200283/hacking/cve-2026-90970-critical-gitlab-ai-gateway-flaw-fixed.html), [CyberPress](https://cyberpress.org/gitlab-patches-critical-ai-gateway-flaw/)
- **Why this matters:** This is the highest CVSS score (9.9) among Row 5's (Tools & Skills/MCP) precedents to date — narrowly above Obot's 9.8, already in the pending backlog — and a distinct mechanism from Row 5's existing entries: not a gateway auth bypass (LiteLLM), not a client-side OAuth trust failure (MCP Python SDK), and not an argument-injection file-write (AWS security-agent-mcp-server), but a sandbox-escape-via-crafted-configuration vulnerability in the AI Gateway product itself — the same "AI Gateway" category this row's own tooling language already references. If approved, it would also change which two items show inline for the first time since this row's cap structure was introduced, and interacts with the still-pending Obot backdating decision (both touch Row 5) — spelled out explicitly in the pending doc.
